# SQE Library Management

## Project Description

The **SQE Library Management System** is a software project developed for the **Software Quality Engineering (SQE)** course. The project is focused on understanding and applying software quality practices through a structured **GitHub-based development workflow**.

The system is designed to support common library operations such as managing books, managing library members, and searching for available books.

## Main Features

* **Book Management** — Add, update, delete, and view book records.
* **Member Management** — Add, update, delete, and view member information.
* **Book Search** — Search for books and check their availability.
* **Issue Tracking** — Use GitHub Issues to track development tasks and problems.
* **Quality Management** — Apply testing, documentation, and software quality practices throughout the project.
